# 代码块高级功能测试

这个页面用于测试我们实现的代码块高级功能，包括行号、文件名显示、代码行高亮和复制按钮。

## 基本代码块

```js
function sayHello() {
    console.log('你好，世界！')
    return 'Hello World!'
}

sayHello()
```

## 带文件名的代码块

```js title="hello.js"
function sayHello() {
    console.log('你好，世界！')
    return 'Hello World!'
}

sayHello()
```

## 同时带文件名和行高亮的代码块

```js title="app.js" {2, 5}
import express from 'express'
const app = express()
const port = process.env.PORT || 3000

app.get('/', (req, res) => {
    res.send('Hello World!')
})

app.listen(port, () => {
    console.log(`服务器运行在 http://localhost:${port}`)
})
```

### Python

```python title="fibonacci.py" {1, 7-8}
def fibonacci(n):
    """计算斐波那契数列的第n项"""
    if n <= 1:
        return n
    else:
        return fibonacci(n-1) + fibonacci(n-2)

print(fibonacci(10))  # 输出: 55
print(fibonacci(20))  # 输出: 6765
```

## 测试主题切换

尝试切换网站的主题，看看代码块的样式如何随之变化。代码块应该会自动适应明亮和暗黑主题。

## 测试复制按钮

每个代码块的右上角都应该有一个复制按钮，鼠标悬停在代码块上时会显示。点击按钮可以复制代码。
